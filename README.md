A make.fun one-liner entry for the **Your Week in One Line** competition: one
line, at most 100 characters, that sums up the week.

## The line

> Fixed one bug, made three, and called it progress.

## Run it

```sh
node main.ts
```

The program writes the entry to `/output/entry.txt` (and prints it).
